# Single-Page-CV
> **PT-BR:** Página única de currículo feita com HTML/CSS puro, pensada para ser leve, rápida e publicar em GitHub Pages.  
> **EN:** Single-page résumé built with pure HTML/CSS, lightweight and fast, ideal for GitHub Pages.

---

## 📌 Descrição | Description

**PT-BR**  
Este repositório contém um **currículo de uma única página** (`index.html`) com ícones/favicons prontos e metadados básicos. É um projeto estático — **não há JavaScript nem backend**.

**EN**  
This repo provides a **single-page résumé** (`index.html`) with ready-to-use icons/favicons and basic metadata. It’s a **static** project — **no JavaScript** and **no backend**.

---

## 🧩 Personalização | Customization

**Onde editar:**  
- `Single-Page CV/index.html`  
  - **Nome, cargo, contato** (e-mail, LinkedIn, GitHub)  
  - Seções: **Resumo**, **Experiência**, **Educação**, **Skills**, **Links**  
- `Single-Page CV/images/`  
  - Favicons e `site.webmanifest` (opcionais)

> Dica: mantenha os links clicáveis (mailto, LinkedIn, GitHub) e valide o HTML no W3C se quiser um plus de qualidade.

---

## ▶️ Como executar | How to run

**PT-BR**  
Abra o `index.html` diretamente no navegador **ou** use o **Live Server** do VS Code (Open with Live Server).  
Como é estático e sem `fetch`, **não há problema de CORS**.

**EN**  
Open `index.html` directly in your browser **or** use VS Code’s **Live Server**.  
Since it’s static and doesn’t use `fetch`, **no CORS issues**.
