## 📄 Descrição / Description

| 🇧🇷 **PT-BR** | 🇺🇸 **EN** |
| --- | --- |
| Projeto estático em HTML/CSS contendo um **currículo de página única**, leve, rápido e ideal para publicação no GitHub Pages. Não utiliza JavaScript — apenas marcação semântica e estilos otimizados. | Static HTML/CSS project implementing a **single-page résumé**, lightweight and fast, perfect for GitHub Pages deployment. No JavaScript — only semantic markup and clean styling. |

## ✨ Personalização / Customization

| 🇧🇷 **Como editar (PT-BR)** | 🇺🇸 **How to edit (EN)** |
| --- | --- |
| Abra `index.html` e personalize:<br>• Nome, cargo e contatos<br>• Resumo<br>• Experiência<br>• Formação<br>• Skills<br>• Links adicionais<br>Imagens e favicons podem ser alterados em `images/`. | Open `index.html` and customize:<br>• Name, role, and contact information<br>• Summary<br>• Experience<br>• Education<br>• Skills<br>• Additional links<br>You may replace favicons inside `images/`. |

## ▶️ Como executar / How to run

| 🇧🇷 **Execução (PT-BR)** | 🇺🇸 **Execution (EN)** |
